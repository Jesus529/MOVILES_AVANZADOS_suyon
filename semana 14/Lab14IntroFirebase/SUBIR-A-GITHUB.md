# Proyecto de la semana 14

El código ya está organizado dentro de este repositorio en **semana 14/Lab14IntroFirebase**. No necesitas volver a subir el ZIP.

El workflow está en **.github/workflows/lab14-ios.yml**, en la raíz del repositorio, y tiene configurado el directorio de trabajo de la semana 14.

Abre **Actions → Compilar iOS y generar capturas → Run workflow** y descarga el artefacto **Lab14-evidencias** al terminar. Contendrá la captura inicial y, si las pruebas llegan a completarse, capturas de registro, sesión y mensajes de dos usuarios. Los registros muestran los fallos si no se completa la ejecución.
