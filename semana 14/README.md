## Compilación y capturas

En GitHub abre **Actions → Compilar iOS y generar capturas → Run workflow**. El workflow está en la raíz del repositorio y compila el proyecto de esta carpeta en un runner macOS. Descarga **Lab14-evidencias** al terminar. Las pruebas generan dos cuentas y dos mensajes de laboratorio en Firebase.

No se han generado capturas ni ejecutado pruebas iOS en Windows. Revisa el resultado del workflow antes de dar las pruebas por aprobadas.
